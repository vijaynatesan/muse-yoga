# Muse Yoga — app

This folder holds the application (server, web app, shared packages, tests). The project overview, quick start,
configuration and privacy notes are in the **[root README](../README.md)**.

Common commands (run from this folder, Node 22+):

```bash
npm install            # also fetches the pose model
node scripts/dev.mjs   # build + start on http://localhost:8080
npm test               # tests
npm run typecheck
```
