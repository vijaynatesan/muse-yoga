# Reference books (bring your own)

Muse Yoga checks that a new asana appears in a reference book before a regular user can create it (admins are exempt).
A built-in list of common asana names is seeded on first start, so this folder can stay empty.

To add your own reference, sign in as an admin and upload a PDF in **Admin → Reference**. The server parses it in the background and indexes the asana names it finds.

No reference PDF is bundled with this repository, for size and redistribution reasons. A good example to download yourself is
*Common Yoga Protocol* (Government of India, 2018). Any PDF you upload is stored under `app/data/` and is not committed.
