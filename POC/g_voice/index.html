Quick check of Muse Voice Transcribe (muse-voice-transcribe-1.0, same API key, server-side only). One click — Start below, like the Start screen. After that, voice only: the app says “Say Ready when you are in position,” listens for up to 10 seconds, then counts if it hears an accepted phrase. Accepted: ready · I’m ready · let us start (plus “let’s start / I am ready”). Audio is never stored.

How it works: this page records microphone PCM, builds a 16 kHz WAV in the browser, and uploads it only when you stop speaking (or at 10 s). The POC server forwards it in memory to POST /v1/asr/transcribe — nothing is written to disk. Streaming (wss://…/asr/realtime) is the production candidate; this POC proves phrases, accuracy, and latency first.
